# Day 21 — Week 3 Review: Perimeter vs. Core

**Goal:** Summarise when to use Model 2 and how it differs from Model 1 for core zones.

## 1. When to Use Model 2

* Zones with significant exposure to outdoors (windows, doors, thin walls).
* Situations where outdoor temperature swings strongly influence warm‑up.

## 2. When to Avoid

* Interior zones shielded from outdoor swings.
* Systems where the ratio becomes unstable or overly aggressive.

## 3. Comparison

Model 1 addresses thermal mass; Model 2 handles weather compensation.  You might combine them later (Model 3).

## 4. Key Takeaway

Recognise zone characteristics.  A perimeter office and an interior conference room behave differently; choose accordingly.
