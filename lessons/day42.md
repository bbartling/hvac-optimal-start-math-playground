# Day 42 — Final Project: Monday Showdown

**Goal:** Apply everything learned to evaluate math vs. human guesses on real Monday data.

## 1. Collect Data

Gather at least 5 real Monday warm‑up events: ΔT, OAT, actual minutes.

## 2. Compute Predictions

For each event:
* Use Model 3 to predict.
* Add 60 min (technician’s guess).
* Multiply by 1.25 (weekend factor).

## 3. Compare

Create a table of actual vs. each prediction.  Which method is closest on average?  Which minimises the maximum error?

## 4. Key Takeaway

The final project shows whether math or intuition wins on Monday — or whether a hybrid is best.
