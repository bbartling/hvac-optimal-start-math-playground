# Day 28 — Week 4 Review: Is it worth it?

**Goal:** Reflect on the cost/benefit of Model 3 versus simpler models and decide when to deploy it.

## 1. Accuracy vs. Complexity

Model 3 can outperform Model 1 in zones where outdoor temperature strongly influences warm‑up.  But it requires data, computation, and parameter tuning.

## 2. Decision Guidelines

* If Model 1 predictions suffice, stick with it.
* Use Model 3 for high‑performance projects or variable OAT climates.
* Always check coefficient sanity.

## 3. Key Takeaway

Smarter models aren’t free.  Deploy complexity where it delivers measurable benefits.
